# My Monetready Product

> A revenue-ready product scaffolded with [Monetready](https://github.com/kory-kaai/monetready).

## Quick start

```bash
npm install
monetready score    # Audit revenue readiness
monetready fire     # Launch checklist
```

## monetready.yaml

Edit `monetready.yaml` to define your product spec, pricing, GTM channels, and revenue playbooks.

## Revenue playbooks

```bash
monetready playbooks list
monetready playbooks run trial-ending-upgrade
```
