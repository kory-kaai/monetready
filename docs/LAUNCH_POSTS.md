## Hacker News (Show HN)

**Title:** Show HN: Monetready – open-source CLI that scores your SaaS revenue readiness (0–100)

**Body:**

I built Monetready because AI agents write code but nobody owns the business outcome loop: validate → price → launch → convert → retain.

Monetready is a self-hosted CLI that:

- Audits your project with a **Monetready Score** (0–100) across pricing, onboarding, conversion, distribution, integrations, and differentiation
- Runs **revenue playbooks** (trial ending, churn win-back, inactive user nudges) via Stripe, Resend, PostHog, Slack
- Generates landing + pricing pages from a single `monetready.yaml` business spec
- Ships a local-first dashboard — no cloud account required

```bash
npx create-monetready my-saas
cd my-saas && npx monetready-cli score
npx monetready-cli launch
```

MIT licensed, runs entirely on your machine. Would love feedback from indie hackers who've shipped but struggled to monetize.

GitHub: https://github.com/kory-kaai/monetready

## Reddit — r/SideProject

**Title:** I built an open-source CLI that scores your SaaS revenue readiness (0–100) and runs lifecycle playbooks

**Body:**

Hey r/SideProject — I kept shipping MVPs that worked technically but had no pricing page, no email flows, no idea if I was "launch ready."

So I built **Monetready**: an open-source, self-hosted CLI that audits six dimensions of revenue readiness and automates the boring GTM stuff.

**What it does:**
- `monetready score` — 0–100 audit (pricing, onboarding, conversion, distribution, integrations, differentiation)
- `monetready launch` — generates landing/pricing pages + launch checklist in one command
- Revenue playbooks — trial-ending emails, churn win-back, inactive user nudges (Stripe + Resend + PostHog)
- Everything runs locally from a `monetready.yaml` business spec

**Try it:**
```bash
npx create-monetready my-saas

npx monetready-cli score
```
